# 夜渡商人

黑夜君臨商人查詢工具，使用 HTML、CSS 與 JavaScript，無需 API key 或後端服務。

## 功能

- 用普通商人最貴的武器辨認共用編號，查詢村落商人商品。
- 攻擊與減傷重點詞條預覽、深夜模式。
- 依編號出現的香藥、噴霧與露滴。
- 傳說武器對應、完整武器及消耗品搜尋。
- 繁體／簡體切換，記住語言偏好。

## 本機使用

在此目錄執行 `python3 -m http.server 8000`，瀏覽器開啟 `http://localhost:8000`。
網站可直接部署至靜態網站主機，不需要建置步驟。

## 資料

遊戲資料依「商人表 v1.02.4 修正版 v2」整理，包含使用者確認的修正。
這是非官方玩家工具；字體轉換不代表不同地區的官方譯名，資料版本不代表目前遊戲版本。
`data.js` 儲存商品資料；`language-maps.js` 為 ICU 74 衍生的繁簡轉換資料。

## 檔案

`index.html`：頁面；`style.css`：樣式；`app.js`：查詢互動；`highlights.js`：重點詞條；`language.js`：語言切換。
